☁️ Google Drive Sync

Connect your Google Drive to back up your links and access them from any device — the same approach the original LaterLinks app uses. Your data is stored in your own Drive (appDataFolder), invisible to other apps.

Don't have one? It's free and takes 3 minutes:

  1. Go to console.cloud.google.com → create a project
  2. Enable the Google Drive API
  3. Configure the OAuth consent screen (External, add your Gmail as test user)
  4. Create an OAuth Client ID of type Web application
  5. Add this page's origin (e.g. http://localhost:8000) to Authorized JavaScript origins
  6. Paste the Client ID above → Sign in
